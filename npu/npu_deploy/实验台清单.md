## 2. 关键一步：ADC 到底出不出数据

```powershell
& 'D:\FPGA\PuTTY\plink.exe' -ssh -batch -pw root root@192.168.137.101 "/opt/npu/tc/probe_fdma"
```

**成功的输出**长这样（producer 必须增长）：

```
[fdma] ID=0x46444d31 FORMAT=0x50343831 STATUS=0x00000013 ERROR=0x00000000
[fdma] t0: producer=0 consumer=0
[fdma] t1: producer=1250 consumer=0  (+1250 blocks in 1s)
[fdma] last frame: V=24.01 V  I=1.50 A  duty=48.7%
[fdma] OK
```

**现在的失败输出**（没有子卡时）：

```
[fdma] FAIL: producer 没有增长 —— PL 没有在产采样
```

如果还是 FAIL，按这个顺序查：

| 现象 | 先查什么 |
| --- | --- |
| ID / FORMAT 不对 | PL 位流不是 DCDC 这版，重新加载位流 |
| STATUS=0x13 但 producer=0 | ADC 没有时钟/没有输入，或子卡没供电 |
| `SIGBUS` | `/dev/mem` 映射问题，先别动，回来告诉我 |
| last frame 的 V/I 是 0 | 输入没接、或 ADC 通道映射不对 |

## 3. 采集 128 Hz 数据

**采集时要把 power_svc 停掉**（两个消费者会抢 FDMA 环；我们的采集器不监听端口，所以 HMI 不会再连进来）：

```sh
/etc/init.d/S99power stop
/opt/npu/tc/fdma_capture --out /root/data/cap_steady.csv --hz 128 --duration 30
/etc/init.d/S99power start
```

成功的输出：

```
[cap] 30.0s: 3750 blocks, 3840 samples -> 128.0 Hz 实际采样率, 文件 /root/data/cap_steady.csv
```

- `--duration 30` 表示采 30 秒（128 Hz × 30 s = 3840 行）
- 文件在 `/root/data/`，行格式 `uptime_s,v_out,i_out,duty`
- **不要用 `/usr/bin/power_svc --csv-hz`**（我改的那版在板上会 Bus error，还没查清）；
  `fdma_capture` 是独立的小工具，只读 FDMA，不碰控制寄存器，已经验证过能正常退出。

## 5. 把数据拉回 PC 并看结果

```powershell
# 拉回来（一次一个文件，或用 -r 整个目录）
& 'D:\FPGA\PuTTY\pscp.exe' -pw root -batch root@192.168.137.101:/root/data/cap_steady.csv D:\deepseek\work\npu_train\out\

# PC 侧看类别时间线（不需要板子）
D:\deepseek\work\npu_train\tc.cmd scan --csv D:\deepseek\work\npu_train\out\cap_steady.csv --rate 128 --hop 1.0

# 板上流式推理（带 IRQ 证据）
D:\deepseek\work\npu_train\tc.cmd live D:\deepseek\work\npu_train\out\cap_steady.csv 128 1.0
```

判据：

- `scan` 的类别和你的实验场景对得上（稳态 = normal、阶跃 = load_transient、临界 = oscillation）；
- `live` 的每窗 `[..]` 分数最高那一类与 `scan` 一致；
- `live` 跑完后 `HARD_NPU_IRQ` 的增量 = 窗口数（`threeclass_live` 每窗 1 次）。

## 7. 如果 ADC 还是不出数据

那就说明不是子卡插不插的问题，而是 PL/ADC 配置问题。这时候需要：

- 确认当前位流版本（`GP0` 的 ID 寄存器：`ADC1`/`CTR1`/`P481`/`FDM1`/`FLT1` 五个 ID 都要匹配）；
- 确认 DTS 里 `0x3FC00000` 的 reserved-memory 存在（`fdma_capture` 已经在用，能访问就说明在）；
- 找做 PL 的同学要 ADC IP 的寄存器手册，对 `ADC_STATUS=0x1D` 逐位解释。

把 `probe_fdma` 的输出发我，我按寄存器位帮你拆。
