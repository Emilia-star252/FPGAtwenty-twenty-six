## 1. 按优先级排列的问题

### P1：ADC 故障后继续保持旧 PWM

位置：`DCDC_top.v:236`，`uispi7606.v:169`、`:180`、`:235`。

`pwm_output_enable = control_rst_n && adc_initialized` 不检查 `adc_error`，也没有样本超时检测。ADC 超时进入 `ST_FAULT` 后不再发布新样本，PI 停止更新，占空比寄存器和 PWM 保留最后的数值。

复现：在测试系数下取得 75% 占空比后，使 ADC 不再拉高 BUSY。约 10 us 后 `adc_error=1`、`adc_ready=0`；继续观察 50 us，无新样本，PWM 仍为 75%。反馈失效时控制仍持续施加原驱动。

建议：加入故障锁存与明确的输出关断策略，并用新样本年龄检测覆盖未产生 `adc_error` 的采样停止。故障处理要允许系统在输出关闭时继续初始化/诊断，恢复条件应明确。

### P1：PI 饱和后冻结全部积分，阻止向内恢复

位置：`PI.v:73`、`:135`。

积分更新条件只看上一拍输出是否饱和：

```text
up = trunc_Q16(Kp * error)
delta = trunc_Q16(up * Ki)
ui = previous_unsaturated ? i1 + delta : i1
i1 = clamp(ui, -10, +10)
v1 = up + ui
out = clamp(v1, umin, umax)
previous_unsaturated = (out == v1)
```

即使积分增量指向退出饱和的方向，仍被禁止。该实现符合源码注释所述的旧 C 算法，但迁移到当前限幅范围后有可复现的功能缺陷：

- 下限：`umin≈0.05`，第一次误差为 0，输出被抬到 0.05，积分被冻结。以后误差持续约 +0.1、`Kp≈0.1`、`Ki=1`，比例量约 0.01 低于下限，8 次更新后积分仍为 0、输出仍为 0.05；相同输入继续保持也无法恢复积分。
- 上限：`umax=4`、`Kp=Ki=1`，首次误差 +6 得到 `i1=6`、输出 4。以后误差变为 -1，需要减小积分，但积分冻结在 6，未限幅输出为 5，8 次更新后仍输出 4；相同输入继续保持会持续卡住。

建议：采用按当前饱和方向和积分增量方向判定的条件积分，或采用回算抗饱和。允许向区间内恢复的积分。积分状态限幅也应与两环各自的输出范围匹配；当前统一 ±10 明显大于电流环 0.05～0.95 的输出范围。

另需保留算法约定：此处 `Ki` 乘在 `Kp*error` 上，不是独立的连续域积分增益。整定时须明确是否采用 `Ki=Ts/Ti` 等离散定义。

### P1：ADC 外部时序尚未被约束证明

位置：`fpga2026.sdc:1`，已有 `fpga2026_chk.timing` 第 10、11 项。

SDC 只有 100 MHz 输入时钟和 `derive_clocks`。工具明确列出：4 个输入无输入延迟，11 个输出无输出延迟。无延迟输入包括 `ad_dout_a`、`ad_dout_b`、`ad_busy` 和 `rst_n`。

每位串行数据在 FPGA 产生 SCLK 下降沿的同一系统时钟沿直接采集。数据从前一个 SCLK 上升沿或 CS 下降沿开始稳定，RTL 给出 80 ns 等待，但需要证明：输出 pad/走线/电平转换 → ADC 数据访问 → 返回走线/电平转换/输入 pad → 采样寄存器的最大延迟满足预算，最小延迟满足保持要求。现在的报告没有外部器件和板级返回延迟依据。

建议：按实际 AD7606 的 VDRIVE、电平转换器、走线和 FPGA I/O 延迟建立接口时序预算，并添加与 100 MHz 采样寄存器及 80 ns 读取节拍一致的约束。不要只对 DOUT 添加 false path；也不要假设添加一个 SCLK 时钟就自动覆盖当前系统时钟采样实现。BUSY 的异步入口到一级同步器、复位同步释放应分别处理，保留同步级之间的正常时序检查。

### 配置阻塞：默认参数尚不构成调节器

位置：`DCDC_top.v:9`、`:15`、`:100`、`:213`。

四个 PI 系数均为 0，没有在工程中发现实际非零参数覆盖。电压环输出恒为 0 A；电流环因为下限为 0.05，首帧之后恒输出约 5%，最终映射为 200/4000 个时钟计数。这是带 ADC 采集的固定占空比运行，不能用其输出判断闭环调节是否正确。

反馈比例仍是 1 个 ADC 码 = 1 V / 1 A 的占位值。必须按电压分压比、传感器灵敏度、极性及零偏标定；带中点偏置的电流传感器还需要偏置扣除。现有顶层没有独立偏置参数。没有功率级模型和这些实际参数，本次不能判断稳定性、带宽或反馈极性是否正确。

### 设计行为核对：初始化期间全低，首次就绪后允许低侧导通

位置：`DCDC_top.v:81`、`:236`、`:238`。

ADC 在 `ST_RESET` 和 `ST_RECOVERY` 期间，`adc_initialized=0`，`pwm_output_enable=0`，四路 PWM 全低，现有初始化关断配置正确。初始化结束进入 `ST_IDLE`、首次 `ready` 后，顶层在下一系统时钟沿锁存 `adc_initialized=1`，允许输出；这早于第一帧 `adc_valid`。此时占空比为 0，两组输出为 H=0、L=1。

因此，“初始化期间全低”和“首次有效采样前低侧已导通”描述的是不同时间区间，并不矛盾。如果设计要求仅为“ADC 初始化期间全低”，此行为满足要求，不应直接列为 P2 缺陷；只有另有“第一帧有效反馈到达前四路保持全低”的要求时，才需要增加使能条件。此前报告将此行为直接分类为 P2，现更正为设计行为说明。

复现：第一次转换 BUSY 卡高，ADC 从未产生有效样本，随后进入故障状态，但低侧仍持续为高。故障发生后没有关断的部分仍属于前述独立的 ADC 故障处理问题。

同样，正常控制的占空比下限为 5%，仅将电流给定降至 0 不会完全关断高侧开关。若功率级需要“首次有效反馈后才允许驱动”或过压/零电流时关闭所有门极，应增加相应输出状态及保护；`duty_counts=0` 在当前结构中不能表示全部门极关闭。

当前两组 PWM 同相，H/L 为逻辑互补，明确未插入死区。RTL 的互补检查通过不能证明物理门极不重叠。若驱动器没有负责死区/互锁，需要结合器件关断延迟补充设计；若由外部驱动器负责，需核对其实际保证。

## 2. 正常链路和拍数

所有控制运算使用同一个 PLL 输出的 100 MHz 时钟。BUSY 使用两级同步器；ADC 两组输出数据原子发布，`adc_valid` 为一个系统时钟周期。电压与电流反馈在同一个状态中锁存，电流环使用本次电压环结果和同一帧电流反馈，没有发现新旧样本混用。

以 ADC 驱动发布 `adc_valid` 的时钟沿为 C0：

| 时钟沿 | 动作 |
|---|---|
| C0 | ADC 帧与 `adc_valid` 发布 |
| C1 | 顶层锁存电压/电流反馈，进入 START_V |
| C2 | 电压 PI 接收输入 |
| C3 | 电压 PI 积分 |
| C4 | 电压 PI 求和 |
| C5 | 电压 PI 限幅，发布结果 |
| C6 | 顶层锁存电流给定，进入 START_I |
| C7 | 电流 PI 接收输入 |
| C8 | 电流 PI 积分 |
| C9 | 电流 PI 求和 |
| C10 | 电流 PI 限幅，发布结果 |
| C11 | 顶层换算并更新 `duty_counts` |
| 下一个周期边界 | PWM 将请求占空比加载到 `duty_active` |

单个 PI 从接收输入到 `out_valid` 是 3 个时钟间隔，即 30 ns；其 FSM 共 4 个处理时钟沿。完整双环从数据发布到占空比请求更新是 11 个时钟间隔，即 110 ns。若 `duty_counts` 在周期加载沿恰好才更新，PWM 会加载旧值、推迟至再下一个周期；本次正常 ADC 时序下有足够裕量，未触发此情况。

## 3. PWM / ADC 的时间预算

| 项目 | 当前实现 |
|---|---|
| 系统时钟 | 100 MHz，10 ns |
| PWM | 边沿对齐，4000 拍，40 us，25 kHz |
| 正常闭环占空比范围 | 200～3800 拍，即 5%～95% |
| 占空比加载 | 只在计数器回卷到 0 时加载 |
| 非零占空比请求位置 | `floor(duty_active/2)`，正常范围内为周期起点后 1～19 us |
| 零占空比请求位置 | 周期起点后 20 us，保持启动采样 |
| 请求脉宽 | 1 拍，10 ns |
| ADC CONVST 低电平 | 4 拍，40 ns |
| 请求发布到 CONVST 上升沿 | FPGA 内部 5 拍，50 ns，未含 pad/板级延迟 |
| SCLK | 6.25 MHz，半周期 80 ns |
| 两路 DOUT 完整帧 | 每路 64 位，含最后低电平保持，共 10.24 us |
| ADC 复位保持 | 默认 83.88608 ms；复位解除后恢复等待 100 ns |
| BUSY 等待超时 | 拉高、拉低阶段各自约 10 us |

仿真 ADC 在 CONVST 后 25 ns 拉高 BUSY、维持 4 us，数据访问延迟设为 30 ns。测得 CONVST 上升沿到 `adc_valid` 发布为 14.290 us；到占空比请求更新为 14.400 us；从原采样请求到占空比请求更新为 14.450 us。

95% 占空比下，请求位于周期内 19 us，按该模型计算，约 33.450 us 时占空比请求就绪，距离 40 us 周期边界还有约 6.550 us。正常读取可赶上下一周期。该预算以无过采样、时钟正常、外部访问时间满足预算为条件。

必须区分“运算完成延迟”和“PWM 实际生效延迟”：在 5%～95% 范围、没有错过下一边界时，从实际 CONVST 上升沿到下一周期 PWM 生效约为 38.950～20.950 us，而不是 110 ns。

采样位置随占空比变化，相邻请求间隔为：

```text
Ts[n] = 40 us + phase[n] - phase[n-1]
```

从 95% 突降到 5% 时为 22 us，反向为 58 us；零占空比到 5% 为 21 us。因此“每 PWM 周期一次”成立，但瞬时采样间隔不固定为 40 us。固定积分系数整定时要纳入这一影响；也可以选择固定相位采样，代价是重新评估开关纹波与边沿干扰。

串行协议核对：AD7606 由 CS 下降沿输出首个 MSB、后续 SCLK 上升沿更新数据、下降沿数据有效；驱动保持 SCLK 初始为高，并在下降沿读取，逻辑极性正确。[ADI AD7606 数据手册 Rev. G，第 28～29 页](https://www.analog.com/media/en/technical-documentation/data-sheets/ad7606_7606-6_7606-4.pdf)。行为模型验证了八通道排列和完整位数，不能替代外部电气时序检查。

闭环整定还要计入 ADC 模拟滤波：该手册表 2 给出 ±5 V 量程的典型群延迟 15 us，另有模拟传感器/前端及 PWM 保持环节。只用数字 PI 的 110 ns 运算延迟估计环路相位裕度会低估总延迟。两环更新频率相同并不要求两环带宽相同；实际带宽需结合功率级模型确定。

- 33 位误差减法 → 33×32 位乘法 → PI `up` 寄存器。
- 49×32 位积分乘法 → 65 位累加/限幅 → `ui`、`i1`。

PI 的多拍 FSM 已把不同算法阶段分开，但每个阶段内部的乘法仍是组合计算，不能据此直接视为满足 10 ns。如果实际系数实现不能收敛，需要再分级或使用 DSP 寄存器流水。
