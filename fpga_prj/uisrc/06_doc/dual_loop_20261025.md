# 电压外环、电流内环恢复

2026-10-25：在当前工程 `fpga_prj/uisrc/01_rtl/DCDC_top.v` 上恢复级联双环，保留现有软启动、前馈、校准、保护、RS485/AXI 命令及遥测接口。

控制链路为：

```text
电压给定 -> 现有软启动 -> 电压外环 PI -> 电流给定 Iref (0～6 A)
                                              |
同一帧 V3 电流反馈 ----------------------------> 电流内环 PI
                                              |
                                  占空比修正量 (-0.2～+0.2)
                                              |
Vsoft / (Vsoft + 24 V) 前馈 -------------------> 相加 -> 最终 5%～95% -> PWM
```

V2/V3 经当前标定后，在同一个 `adc_valid` 帧一起锁存。先等待电压 PI 完成、锁存电流给定，再启动电流 PI；占空比只在电流 PI 完成后更新。两环均随现有 25 kHz 完整样本更新。V3 仍是原有电流测量通道，本次没有改变采样位置或将其改称为电感电流。

参数与限幅：

| 项目 | 当前值 | 含义 |
|---|---|---|
| `V_KP_Q16` / `V_KI_Q16` | 66 / 655 | 沿用恢复前的数值；外环输出单位现在为 A，仍需双环整定 |
| `I_KP_Q16` / `I_KI_Q16` | 655 / 1311 | 用户指定 Kp=0.01、Ki=0.02，按 Q16 四舍五入 |
| `I_REF_MIN_Q16` / `I_REF_MAX_Q16` | 0 / 393216 | 外环电流给定限幅 0～6 A |
| `DUTY_MIN_Q16` / `DUTY_MAX_Q16` | -13107 / 13107 | 沿用当前修正范围，现作用于电流内环输出 |
| 最终 PWM 计数 | 200～3800 / 4000 | 保留前馈叠加后的 5%～95% 限幅 |

PI 的积分公式与高精度实现沿用当前 `PI.v`，仍为 `Kp * error * Ki`。Q16 编码后的 Kp 约为 0.0099945、Ki 约为 0.0200043；本次没有改变 Ki 的算法定义。原单环的 PI 直连语句保留为注释，未提供实物闭环整定结论。

2026-10-25 参数更新：用户指定外环给定 0～6 A、内环 Kp=0.01、Ki=0.02。过流保护仍为**实测电流严格大于 4 A**触发，与 6 A 内部电流给定限幅独立；本次未放宽保护阈值。

2026-10-29 参数更新：用户将过流关断阈值改为 **2.5 A**，Q16 常量为 `163840`；有效采样的标定电流严格大于 2.5 A 时关断并锁存。清故障要求最近有效样本电流 <=2.5 A。内部电流给定上限仍为 6 A。
